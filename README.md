# AIプロンプトメーカー V2

Androidスマートフォンのブラウザで、設定を保存・再利用しながら画像生成用プロンプトを作るツールです。画像生成や外部AI APIへの接続は行いません。

## スマートフォンで使う

公開中のGitHub Pages: https://ohta1057dar-ui.github.io/ai-image-tool/

**V2のブランチをmainへマージするまでは、公開ページは従来版です。** 公開設定がmainを参照している場合、レビュー後のマージでV2に更新されます。

1. 「作成」で人物説明・衣装・シーン・構図を入力します。人物の詳細は折りたたみ欄から開けます。
2. 画像比率とスタイルを選択します。通常プロンプトは入力に合わせて自動更新されます。
3. 「プロンプトを作る・結果を見る」で完成文章へ移動します。
4. 通常プロンプトとネガティブを個別にコピーし、画像生成サービスへ貼り付けます。
5. 残したい組み合わせは「履歴に保存」で保存します。

管理用キャラクター名は、一覧で識別するための名前です。生成文章には入りません。外見は「人物説明」や詳細欄に入力してください。比率は文章に含めますが、生成サービス側でも画像サイズの設定が必要な場合があります。ネガティブ欄の対応はサービスによって異なります。

## 保存設定と履歴

- 作成画面の保存ボタンで、キャラクター・衣装・シチュエーション・構図を名前付きで保存できます。
- 各選択欄、または「保存設定」の「読み込む」で再利用できます。
- 読み込み後の編集は元データを変更しません。変更版は別の名前で保存してください。同じ名前でも別の設定になります。
- 保存設定は削除できます。名前変更・直接上書きは未対応です。
- 作成途中の入力は自動保存され、ページを閉じても同じブラウザで復元されます。
- 履歴は新しい順に最大100件。101件目で最も古い履歴が除かれます。
- 履歴には完成文章・ネガティブ・入力設定を保存します。「入力を復元」は現在の入力を置き換えます。
- 履歴の通常プロンプト・ネガティブのコピーと削除ができます。

## 保存場所と注意点

すべてのデータは `localStorage` の `ai-prompt-maker-v2` に保存されます。アプリからデータをサーバーへ送信しません。サーバーやデータベースは不要です。

保存内容は端末・ブラウザ・サイトのオリジン（ドメイン等）に紐づきます。別端末との同期はありません。ブラウザデータの削除、プライベートモード等では消える可能性があります。重要な文章は別途メモ等にもコピーして残してください。JSONバックアップ・復元は次の段階で追加する予定です。

容量不足や保存制限があると警告が出ます。その場合、設定や履歴の保存完了は表示しません。読み込めない保存データがある場合は、元データを上書きせず保存を停止します。コピーはHTTPSのGitHub Pagesでの利用を推奨します。自動コピーに失敗した場合は、表示された文章を長押ししてコピーできます。

複数のタブを同時に開いた場合の保存競合は未対応です。基本的に1つのタブで使用してください。

## ファイル構成と更新方法

- `index.html`: 日本語の画面、入力欄、3タブ、保存ダイアログ
- `style.css`: 紫系の見た目、1列表示、固定の下部ナビゲーション
- `script.js`: 文章の組み立て、ブラウザ内保存、設定・履歴、コピー
- `README.md`: 使い方と管理方法

HTML・CSS・JavaScriptのみ。外部ライブラリ、インストール、ビルド作業は不要です。GitHubでファイルを編集する場合は作業ブランチで変更し、確認後にmainへマージします。画面ラベルはHTML、色や大きさはCSS、文章生成と保存処理はJavaScriptで管理します。保存データ形式を変える場合は既存データの移行処理が必要です。

## 開発時の確認

```bash
node --check script.js
python3 -m http.server 8000
```

PCのブラウザで http://localhost:8000 を開けます。スマートフォンからのlocalhostはPCとは別です。スマートフォンでは公開HTTPSページ等の到達できるURLを使ってください。

確認項目: 入力の自動更新、再読み込み後の入力復元、4種類の設定保存と再利用、通常・ネガティブのコピー、履歴保存・復元・削除、履歴100件上限、狭い画面の横はみ出し、キーボード表示中の入力操作。
