# AIプロンプトメーカー V2.1

Android Chromeで、固定人物に衣装・シーン・表情・構図・仕上がりを組み合わせ、画像生成用の日本語プロンプトを作るツールです。HTML/CSS/JavaScriptのみ。外部ライブラリ・ビルド・API・サーバー・データベースは不要です。画像そのものは生成しません。

V2.1は `codex/ai-prompt-maker-v2-1` で開発しています。V2コミット `a4803cf3a7aaceb51ebcf5ea7dde3280c0e01d1a` をベースにしています。**mainへのマージとGitHub Pagesの公開元変更は行っていません。**

従来の公開ページ: https://ohta1057dar-ui.github.io/ai-image-tool/

## 少ない操作で作る

1. 「作成」上部のクイック作成で、人物・衣装・シーン・表情/動作・構図/カメラ・仕上がりを選択します。お気に入りは★付きで上に並び、最大2件のお気に入りと最近使った1件をタップ候補として表示します。
2. 設定を変更したいときだけ、そのカテゴリのカードを開きます。閉じたカードに設定名と✓が表示されます。詳細欄はさらに折りたたまれています。
3. 完成文章は自動更新されます。画面下部の「結果を見る」で完成文章へ移動し、「コピー」で通常プロンプトをコピーできます。
4. ネガティブは別欄・別ボタンでコピーします。空欄からは文章を生成しません。
5. 残したい組み合わせは「履歴に保存」。最新100件まで保存し、101件目で最も古い履歴が除かれます。

管理名は一覧・カード・履歴で識別するためのものです。通常プロンプトには出力しません。管理名のみでは通常プロンプトを作成しません。人物や衣装の説明など、生成に使う内容も入力してください。

## 6種類の設定

| カテゴリ | 設定できる内容 |
| --- | --- |
| 人物 | 管理名、年齢、人物説明、顔立ち、髪型/髪色、目、肌、メイク、体型、身長、身体的特徴、その他の特徴、固定/維持する特徴、補足 |
| 衣装 | 管理名、衣装説明、種類、色、素材、デザイン、靴、アクセサリー、その他 |
| シーン | 管理名、状況、場所、時間帯、行動、周囲の人物、照明、雰囲気、小物、背景、その他 |
| 表情・動作 | 管理名、表情、視線、口元、身体の動作、手の動き、人物同士のやり取り、その他 |
| 構図・カメラ | 管理名、構図説明、撮影範囲、方向、高さ、距離、アングル、ポーズ、視線、撮影者、機材感、レンズ感、背景ボケ、その他 |
| 仕上がり | 管理名、比率、表現形式、機材感、光、色調、被写界深度、画質/質感、その他 |

比率: 9:16 / 4:5 / 1:1 / 3:4 / 16:9。
表現形式: 実写・フォトリアル / スマートフォン写真風 / イラスト / アニメ。

衣装は衣装説明だけでも保存できます。他カテゴリも必要な項目だけで構いません。未入力の詳細は生成文章から除外されます。既定の比率は9:16、表現は実写・フォトリアルです。比率は生成サービス側でも指定が必要な場合があります。

## 保存設定を管理する

「保存設定」のカテゴリ選択で1カテゴリだけ表示します。

- 読み込み: 作成画面へ反映し、そのカードを閉じます。元の保存設定は変更しません。
- 編集: 別の編集画面で内容を変更し、明示的に保存します。ID・作成日時・お気に入りは維持し、更新日時を変更します。作成途中の入力は変更しません。更新版を使う場合は再度読み込んでください。
- 複製: 新しいIDで「（コピー）」を付けて保存します。
- 削除: 確認後に削除します。作成途中の入力と過去の履歴は残ります。
- ☆/★: お気に入りを切り替えます。保存一覧とクイック選択で優先表示します。

作成画面から保存する場合は新規保存です。同じ名前でも別の設定になります。管理名を省略した場合は内容から名前候補が作られ、保存時に変更できます。

## 文章の組み立てと履歴

AI APIを使わず、入力内容から決定論的に指示文を組み立てます。表現→人物→外見→一貫性→衣装→表情/動作→シーン→構図→光/色/質感→比率の順です。管理名、空欄、ネガティブは通常文章に混ぜません。未入力の光や肌加工等は追加しません。

表情・動作の視線が入力されている場合は、構図の視線より優先します。V2の人物に保存された表情は人物詳細の「V2から引き継いだ表情」に残ります。表情・動作で表情を指定するとそちらを優先します。新しい表情が空欄の場合は旧表情を使います。不要なら旧表情欄を消してください。

履歴は人物・衣装・シーン・比率・日時を短く表示し、「プロンプトを見る」で全文を展開します。通常・ネガティブを個別コピーでき、確認後に設定復元・削除ができます。履歴の完成文章は保存時の文章をそのまま保持し、復元後の作成画面ではV2.1の文章生成処理で再構成します。

## V2データとの互換性

- V2は `localStorage` の `ai-prompt-maker-v2`、V2.1は `ai-prompt-maker-v2-1` を使います。
- V2.1データがない初回のみV2から移行します。**V2のキーは変更・削除しません。** V2.1保存形式は `version: 3` です。
- 人物・衣装・シチュエーション・構図の保存設定、ID、作成日時、履歴、作成途中の入力を保持します。
- 新しい詳細項目は空欄、favoriteはfalse、表情/動作と仕上がりの保存一覧は空で開始します。V2の比率と画像スタイルを引き継ぎます。
- 旧「実写風」「イラスト風」「アニメ風」は、それぞれ「実写・フォトリアル」「イラスト」「アニメ」に変換します。
- 各保存設定に id / type / name / createdAt / updatedAt / favorite / version / data を持たせています。将来画像をIDに紐づけられますが、画像機能はありません。
- V2.1を使い始めた後のV2での変更は自動同期しません。
- 読めない保存データがある場合は上書きせず、自動保存を停止して警告します。確認付きの正しいJSON復元で再開できます。

同じ端末・ブラウザ・オリジンでのみ自動移行できます。GitHub Pagesとraw.githackは別の保存領域です。raw.githackのコミット固定URL同士は同じオリジンのため保存領域を共有します。別端末・別オリジンへはJSONで移してください。

## JSONバックアップと復元

「保存設定」下部の「バックアップ・復元」から操作します。

- 書き出し: 全6カテゴリ・お気に入り・最近の使用設定・履歴・作成途中の入力をJSONファイルへ保存します。
- 読み込み: ファイルを選択します。JSON形式、version、項目型、ID、日時、メタデータ、履歴100件上限を確認します。10MBまで対応します。
- 復元前に設定/履歴の件数と置換確認を表示します。キャンセルするとデータは変わりません。
- V2形式（version: 2）の保存データJSONも読み込めます。
- 保存に失敗した場合は、既存のデータ・画面入力を置き換えません。
- 保存データが破損しているときの書き出しには、取得可能な元の保存文字列を `recoveryData` に含めます。これは調査用で、自動復元対象ではありません。

ブラウザデータを削除すると保存内容も消えます。バックアップを定期的にダウンロードし、ファイルがあることを確認してください。サーバー送信・クラウド同期は行いません。複数タブ同時編集の競合は未対応です。1つのタブで使ってください。

## ファイルと管理方法

- `index.html`: 3タブ、クイック作成、入力カードの配置、結果、各ダイアログ
- `style.css`: 紫系デザイン、折りたたみ/コンパクト表示、固定ナビ、安全領域、キーボード時の調整
- `script.js`: SCHEMA（入力項目定義）、生成文章、保存管理、移行、コピー、バックアップ
- `tests/v2-1.test.cjs`: 外部依存なしの模擬機能テスト
- `README.md`: 使い方、互換性、確認方法

項目を追加する場合はJavaScript先頭のSCHEMAと文章生成処理を確認してください。保存キー・項目キーの変更には移行処理が必要です。色とサイズはCSSで管理します。

## 検証方法

```bash
node --check script.js
node tests/v2-1.test.cjs
git diff --check
```

DOM・localStorage・Clipboard APIを模擬して実際のJavaScriptを実行するテストです。ブラウザの見た目、実際のクリップボード、ダウンロード、キーボード動作は実機確認が必要です。環境のソケット制限でChromiumを起動できないため、ブラウザテストは実行していません。Playwright等の依存関係は追加していません。

V2.1の検証ではJavaScript構文チェック、差分チェック、模擬テスト41項目が成功しました。移行、6カテゴリ保存、編集/複製/削除、お気に入り、コピー、履歴、JSONの正常/不正/キャンセル/保存失敗を含みます。

PCで動かす場合は `python3 -m http.server 8000` で http://localhost:8000 を開けます。スマートフォンのlocalhostはPCとは別です。AndroidではHTTPSの確認URLを開いてください。

### Android Chromeでの確認

1. 通常タブで確認URLを開き、V2の設定・入力・履歴が残っているか確認する。まずJSONバックアップを取る。
2. 6カテゴリをクイック選択し、閉じたカードの名前、✓、自動生成文章を確認する。
3. カードと詳細欄を開閉し、新しい詳細を入力する。カード内で保存し、再読み込み後も残ることを確認する。
4. 保存設定のカテゴリ切り替え、編集、複製、お気に入り、削除を試す。読み込みと編集で元設定/作成入力が意図せず変わらないことを確認する。
5. 下部の「結果を見る」「コピー」とネガティブコピーを試し、メモアプリへ貼り付ける。
6. 履歴保存→入力変更→復元→削除を試す。
7. JSONをダウンロードし、入力を変えてから読み込み、キャンセルと復元の両方を試す。
8. キーボード表示中の画面下部、Androidシステムナビ、縦/横向き、長い名前や文章の表示を確認する。

Android Chromeの `interactive-widget=resizes-content` とsafe-areaに対応し、非対応環境ではvisualViewportを参照して固定ボタンの占有を減らします。実機のキーボードや表示設定により挙動が異なるため、操作性は実機で最終確認してください。

## 今回の対象外と制限

画像生成/ChatGPT API、SNS投稿、ログイン、外部データベース、クラウド同期、参照画像/IndexedDBは未実装です。日本語文章を各生成サービスに合わせて翻訳・最適化する処理もありません。各カテゴリに相反する自由入力をした場合、表情と視線の優先処理以外は自動的に整合させません。比率やネガティブ対応は生成サービス側で確認してください。
