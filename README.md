# AI画像生成プロンプト管理ツール

スマートフォンのブラウザで、画像生成用のプロンプトを簡単に組み立てるための最小版ツールです。
画像生成APIには接続せず、入力した内容からプロンプトを作成・コピーします。

## 使い方

1. `index.html` をブラウザで開きます。
2. キャラクター名、衣装、シチュエーション、構図を入力します。
3. 「プロンプトを作る」をタップします。
4. 「コピーする」をタップすると、生成されたプロンプトをコピーできます。

ローカルサーバーで表示する場合は、このフォルダーで次のコマンドを実行し、
ブラウザで `http://localhost:8000` を開いてください。

```bash
python3 -m http.server 8000
```

## ファイル構成

- `index.html`: 画面の内容
- `style.css`: スマートフォン向けの見た目
- `script.js`: プロンプト作成とコピーの処理

外部ライブラリやビルド作業は必要ありません。
